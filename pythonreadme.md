# Python Case Studies

This repository contains 10 beginner-friendly Python programs based on
simple real-life problems. Each program is saved in a separate `.py`
file.

## Python Concepts Used

-   `input()` and `print()` for input and output.
-   Variables and data types such as `int`, `float`, and `str`.
-   Arithmetic operators for calculations.
-   Conditional statements: `if`, `elif`, and `else`.
-   Loops: `for` and `while`.
-   Lists and list methods such as `append()`.
-   Built-in functions such as `len()`, `max()`, `min()`, and `sum()`.
-   Nested loops for pattern printing.

## Requirements

-   Python 3 installed on your computer.
-   A code editor or terminal, such as Visual Studio Code.

## How to Run

1.  Download or clone this repository.

2.  Open the project folder in your code editor or terminal.

3.  Run any program using:

    ``` bash
    python case1.py
    ```

4.  Replace `case1.py` with the name of the program you want to execute,
    from `case1.py` to `case10.py`.

On some systems, use `python3` instead of `python`:

``` bash
python3 case1.py
```

## Note

Each program runs independently and asks the user to enter the required
values. The filenames in this README use simplified names (`case1.py` to
`case10.py`); keep the actual uploaded filenames or rename the files to
match before using the example commands.
