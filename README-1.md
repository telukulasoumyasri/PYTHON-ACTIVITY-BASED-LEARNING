# Black Cherry Restaurant Website

## About the Project
**Black Cherry** is a simple restaurant website built with HTML and CSS. It introduces the restaurant, displays a food menu with prices, shares information about the restaurant, and provides contact details and a message form.

## Features
- **Home page:** Welcome message, navigation links, and an Explore Menu button.
- **Menu page:** Six food items with descriptions, prices, images, and Order Now buttons.
- **About Us page:** Restaurant introduction and values such as fresh food, care, and customer experience.
- **Contact page:** Address, phone number, email, opening hours, and a message form.
- **Styling:** Coordinated colours, navigation bars, cards, spacing, and hover effects using CSS.

## Technologies Used
- HTML5
- CSS3

## How to Run the Website
1. Download or copy all project files into the same folder.
2. Keep the image files used by the pages in that folder too.
3. Open `Cherry_home.html` in a web browser.
4. Use the navigation links to visit the Menu, About Us, and Contact pages.

You can also open `Cherry_home.html` in Visual Studio Code and use a local preview extension such as Live Server.

## Important Notes
- The **Order Now** buttons are currently visual buttons; ordering functionality has not been implemented.
- The contact form is currently a front-end form only. It does not send or store messages without additional backend or form-service integration.
- The website uses separate HTML and CSS files and does not currently include JavaScript.
